This module enables management of dock reservations for loading and unloading operations using OCA's resource booking system. It integrates with Odoo Inventory and allows associating multiple pickings to a dock reservation, with calendar-based scheduling and collision prevention.

Features
--------
- Link stock pickings to dock reservations (resource bookings)
- Prevent overlapping reservations for the same dock/time slot
- Calendar interface with enhanced filters and color coding
- Synchronization between picking scheduled date and reservation
- Automatic reservation creation on picking confirmation
- OCA-compliant, no core modifications

Usage
=====

1. Install the module and its dependencies (`resource_booking`, `delivery_dropoff_site`).
2. Configure dock resources in Odoo Resource Management (resource_type = 'material').
3. Confirm a picking to auto-create a dock reservation, or manually link pickings to a reservation.
4. Use the calendar view to manage and filter dock reservations.
5. Edit or cancel reservations as needed; pickings and bookings remain synchronized.

See the calendar and form views for enhanced navigation and filtering.
